<p>Futebol. A Mesa da Assembleia Geral do Operário agendou para o próximo dia 23 uma Assembleia Geral Extraordinária (AGE) para a eleição dos órgãos sociais do clube para o quadriénio 2026/2030. Esta será a segunda assembleia geral dos “fabris” para o efeito este ano, dado que no passado mês de maio não surgiram listas às eleições, tendo posteriormente sido constituídas uma Comissão de Gestão e uma de Fiscalização para gerir os destinos do clube da cidade da Lagoa durante seis meses. Findo esse prazo, o clube vai tentar, uma vez mais, solucionar a crise diretiva, numa AGE que tem três pontos na ordem de trabalhos: Apresentação e votação das listas para o quadriénio 2026/2030; no caso de continuar a não haver lista para os corpos sociais do clube, nomear uma Comissão de Gestão e uma de Fiscalização com a duração máxima de seis meses; outros assuntos de interesse para o clube. A AGE, no dia 23 de novembro, está marcada para as 20h30 na sede social do Operário.</p>
